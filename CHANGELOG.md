# Changelog

## Yayınlanmamış

- Ping Scanner: canlı hostların MAC adresi ve markası gösteriliyor (ARP + IEEE OUI)
- Port Scanner: yerel ağdaki hedefin markası gösteriliyor
- SNMP Collector: `sysObjectID` okunuyor, cihaz markası gösteriliyor
- Whois / IP Info, SSH Failed Login ve SNMP sonuçları kaydediliyor ve raporlanabiliyor
- Yeni bağımlılık: `netaddr`
